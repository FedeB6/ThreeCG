# Progetto esame Fondamenti di Computer Graphics - Modulo 2 

## Federico Bianchi - s0001195209

### Little Garden App
Progetto realizzato per l'esame di Fondamenti di Computer Graphics M (modulo 2).
Il progetto mette a disposizione dell'utente una webApp in cui può interagire tramite mouse con un piccolo giardino virtuale. L'utente potrà tramite pannello di controllo laterale selezionare l'azione che intende eseguire e conseguentemente eseguirla cliccando su uno degli appezzamenti di terreno disponibili.
Il progetto è stato sviluppato, come da requisiti, usando la libreria Three.js.
